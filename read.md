# Expense Tracker Web App

## Project Preview

![Expense Tracker Screenshot](screenshot.png)

---

A modern Expense Tracker Web Application built using Flask, SQLite, HTML, CSS, and JavaScript.

## Features

- Add Income & Expenses
- Dashboard Summary
- Balance Calculation
- Transaction History
- Delete Transactions
- Doughnut Chart Analytics
- Responsive Modern UI

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Chart.js
