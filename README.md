# 💰 Expense Tracker Web Application

A modern full stack Expense Tracker Web App built using Flask, SQLite, HTML, CSS, and JavaScript.

---

## 🚀 Project Preview

![Expense Tracker Screenshot](screenshot.png)

---

# ✨ Features

✅ Add Income & Expenses  
✅ Automatic Balance Calculation  
✅ Transaction History  
✅ Delete Transactions  
✅ Doughnut Chart Analytics  
✅ Responsive Modern UI  
✅ Full Stack Architecture  

---

## Frontend

# ⚙️ How to Run

## 1️⃣ Install Flask

```bash
pip install flask
```

## 2️⃣ Run the Application

```bash
python app.py
```

## 3️⃣ Open Browser

```text
http://127.0.0.1:5000
```

# 📊 Project Functionalities

- Users can add income and expense transactions
- System automatically updates balance
- Transactions are stored using SQLite database
- Dashboard displays graphical analytics using Chart.js
- Users can delete transactions dynamically
