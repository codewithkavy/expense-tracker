# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/codewithkavy/expense_tracker.git
```

---

## 2️⃣ Install Dependencies

```bash
pip install flask
```

---

## 3️⃣ Run Application

```bash
python app.py
```

---

## 4️⃣ Open in Browser

```text
http://127.0.0.1:5000
```
